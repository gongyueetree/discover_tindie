# Four tool areas and inline reading (v14)

Navigation: Components → Explore circuits → PCB planner → Resources. Removed top Discover navigation and standalone Project viewer/BOM tools navigation. Resources reuses the original Discover content and data loading; `/discover` redirects there. Home cards follow the same four areas; removed duplicated Discover and standalone BOM sections from the home/embed pages.

Explore circuits opens an in-page project viewer for catalogue cards. Upload project selects local files before opening the viewer; Import GitHub URL opens the viewer's existing repository scanner and project selector. Source project links from component details and the relationship graph target this flow. Previous `/tools/viewer` links redirect with their project/example parameters preserved. Existing supported formats and download provenance restrictions remain unchanged. The viewer's Match this BOM action switches to its embedded BOM tab. Standalone BOM routes remain for compatibility, with no navigation tab.

Datasheets: component details and planner component modals now use Read datasheet. A nested modal fetches the PDF through a bounded same-origin reader endpoint and displays a browser PDF iframe using a temporary object URL, revoked on close. No automatic file download is triggered. The endpoint overrides upstream attachment disposition with inline, checks PDF signature, limits responses to 30 MB, validates each redirect against allowed HTTPS manufacturer/distributor hosts and times out after 25 seconds. Additional trusted storage hosts can be configured with MAKER_DATASHEET_HOSTS. A blocked, inaccessible or non-PDF source displays an error rather than silently downloading. PDF display relies on browser PDF support (desktop Chrome/Safari etc.); actual rendering needs browser verification.

Validation: TypeScript/production build, existing Maker and family-graph regression checks; PDF tests verify inline response, denied host, redirect to private host rejection and non-PDF rejection. No production deployment or GitHub push.
